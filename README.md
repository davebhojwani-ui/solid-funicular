# Dave Elliott Wave Analyzer

Streamlit app for uploading OHLCV CSV files and generating multi-degree Elliott Wave charts.

## Files
- app.py
- requirements.txt
- README.md

## Deploy on Streamlit Cloud
1. Create a GitHub repository.
2. Upload app.py and requirements.txt.
3. Go to Streamlit Cloud.
4. Choose **Deploy a public app from GitHub**.
5. Select your repo.
6. Main file path: `app.py`.
7. Click Deploy.

## CSV format
Required columns:
- Date
- Open
- High
- Low
- Close

Optional:
- Volume
